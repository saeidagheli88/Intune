Windows Remove-App Script Generator

Type a Windows app's details → get a ready-to-deploy removal .ps1 (Monster house style: SYSTEM, 64-bit, C:\ProgramData\Monster\Logs, exit 0/1). Based on the PatchMyPC Pre-Install / Uninstall-Software pattern.
Matched with -like against Add/Remove Programs DisplayName. Wildcards * allowed. Keep patterns TIGHT — a broad pattern like *App* can match unrelated software.
Extra safety gate: entry must also match this Publisher.
Used only when the entry has no QuietUninstallString. NSIS = /S, Inno = /VERYSILENT /NORESTART, InstallShield = /s
Each is Test-Path guarded and must be at least 3 path segments deep (the script refuses to delete drive roots or top-level folders).
